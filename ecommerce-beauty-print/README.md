# Elixir-216: E-Commerce Beauty & Printing Platform

A full-stack e-commerce platform specializing in perfumes, cosmetics, and printing services.

## 🎯 Features

- 💄 Beauty Products (Perfumes, Cosmetics)
- 🖨️ Printing Services
- 🛒 Shopping Cart
- 💳 Payment Integration (Stripe)
- 📦 Order Management
- 👤 User Accounts & Authentication
- ⭐ Reviews & Ratings
- 🔍 Advanced Search & Filters
- 📊 Admin Dashboard
- 📱 Responsive Design

## 🛠️ Tech Stack

**Frontend:**
- React 18+, Redux Toolkit, Tailwind CSS, Vite

**Backend:**
- Node.js, Express, MongoDB, Stripe, JWT

## 📁 Structure

```
ecommerce-beauty-print/
├── frontend/     (React app)
├── backend/      (Express API)
└── README.md
```

## 🚀 Getting Started

```bash
# Frontend
cd frontend && npm install && npm run dev

# Backend
cd backend && npm install && npm run dev
```
